# Bootstrap Learning 🚀

This repository contains my practice and learning journey with **Bootstrap**, a popular CSS framework used to build responsive and attractive websites quickly.

## 📚 What is Bootstrap?

Bootstrap is a free, open-source CSS framework that provides ready-made styles, components, and utilities to create responsive websites with less custom CSS.

## 🎯 What I'm Learning

I'm learning Bootstrap by exploring simple concepts, experimenting with examples, and applying them to different website elements.

- **Containers & Grid System** — Creating layouts and arranging elements.
- **Buttons & Colors** — Styling buttons and text.
- **Navbar** — Building responsive navigation bars.
- **Cards** — Displaying content in organized sections.
- **Forms** — Creating styled input fields.
- **Utilities** — Managing spacing, alignment, and sizing.
- **Responsive Design** — Making websites work on different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5

## 💡 Learning Approach

Learn a concept → Find a simple example → Experiment with it → Apply it to a webpage → Improve through practice.

---

**Purpose:** To build a strong foundation in Bootstrap through hands-on practice and small examples.
